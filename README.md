# Youtube 视频字幕处理工具

这是一个本地视频处理工具，用于下载或读取视频，生成字幕、翻译字幕、校正字幕，并逐步扩展到字幕烧录和内容切片。

## 当前能力

- 下载视频和说明信息。
- 生成中英双语字幕。
- 烧录字幕到视频。
- 读取本地视频、音频或 SRT 字幕。
- 本地语音识别后导出 SRT。
- 合并短句。
- 使用大模型检查英文识别结果。
- 翻译中文字幕。
- 导出英文、中文或中英双语字幕。

## 启动方式

双击：

```text
打开网页版.bat
```

程序会启动本地网页版本。

## 长期更新文档

项目路线、已完成内容、后续计划都记录在：

```text
更新文档.md
```

## GitHub 上传规则

- 上传程序代码、页面、说明文档、字幕文本、项目记录。
- 不上传源视频、源音频、烧录成品视频、切片视频。
- 本地处理文件默认放在 `downloads` 下，只有未来 `downloads/projects` 里的文档、字幕和 JSON 记录会按需上传。

## 目标流程

1. 下载或读取源视频。
2. 保留源文件和原始信息。
3. 识别字幕并生成带时间轴的 SRT。
4. 合并短句。
5. 使用大模型校正英文。
6. 翻译中文字幕。
7. 导出字幕和烧录视频。
8. 根据内容生成 10 个 2-5 分钟切片候选。
9. 用户调整后导出最终切片。
